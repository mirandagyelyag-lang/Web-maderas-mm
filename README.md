# Maderas M&M 🌲

Sitio web oficial de **Maderas M&M**, aserradero chileno dedicado a madera bruta y elaborada, productos a medida y soluciones para construcción y proyectos en madera.

## Sitio

La web incluye:

- Catálogo de productos y terminaciones
- Comparador visual de pino bruto y cepillado
- Información sobre especies trabajadas
- Cotización y contacto directo
- Asistente virtual para consultas de productos
- Panel de administración para conversaciones

## Tecnologías

- React
- Vite
- Tailwind CSS
- Supabase
- Vercel
- Lucide React

## Estructura

```text
api/             Funciones de servidor
public/assets/   Imágenes y recursos visuales
src/components/  Componentes de interfaz
src/hooks/       Hooks reutilizables
src/lib/         Utilidades y servicios
src/pages/       Páginas de la aplicación
```

## Desarrollo local

```bash
npm install
npm run dev
```

Para comprobar una versión de producción:

```bash
npm run build
npm run preview
```
