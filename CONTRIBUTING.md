# Contribuir

Este repositorio contiene el sitio web de Maderas M&M.

## Antes de hacer cambios

1. Revisa que el cambio corresponda al sitio y no altere información comercial confirmada.
2. Evita inventar precios, stock, medidas o condiciones de despacho.
3. Mantén la experiencia responsive y comprueba especialmente la versión móvil.
4. Reutiliza componentes y estilos existentes antes de agregar nuevas dependencias.
5. No subas claves, tokens ni credenciales al repositorio.

## Convención de commits

Usa mensajes breves y descriptivos, por ejemplo:

```text
Mejorar catálogo en móvil
Actualizar medidas de pino dimensionado
Corregir imagen de producto
```

## Antes de publicar

```bash
npm run lint
npm run build
```

Comprueba también que las imágenes carguen correctamente y que los enlaces de contacto sigan funcionando.
