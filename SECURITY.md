# Política de seguridad

## Reporte de vulnerabilidades

Si encuentras una vulnerabilidad de seguridad en este proyecto, evita publicarla en un Issue abierto junto con credenciales, claves, datos personales o instrucciones que permitan explotarla.

Para problemas generales de funcionamiento puedes utilizar las plantillas de Issues del repositorio.

## Información sensible

Este repositorio no debe contener claves privadas, tokens de acceso, contraseñas ni credenciales administrativas. Las credenciales sensibles deben mantenerse en variables de entorno de los servicios correspondientes.

## Alcance

Esta política cubre el código y la configuración pública del sitio web de Maderas MYM.
